# AS400 → Spring Boot AI 数字员工

> 版本：V1.0（方案评审稿，2026-10-25）
> 状态：待评审，尚未实施

本仓库是一份**架构设计 + 技术决策学习笔记**，不是可运行代码。

目标：在 Claude Code + 项目级 `.claude/skills/` 的基础上，构建一个后台无人值守的迁移数字员工，先完成「单个 AS400 画面及其关联部品」的端到端 RPG/DDS → Spring Boot 迁移。

## 核心结论（一句话）

> 大模型负责理解、规划和处理不确定性；确定性程序负责状态、权限、执行、重试、验收门禁和证据保存。

第一版不建大平台、不堆多 Agent，先让**一个真实画面**从工单到交付形成可靠闭环——失败时正确 BLOCKED/FAILED，而不是假装成功。
